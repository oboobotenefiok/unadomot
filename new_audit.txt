D. DEFAULT DECISIONS (use these unless a human overrides)
==============================================================================
D1  Launch scope (beta): email/password + Google sign-in, email verification,
    password reset, browse/search/filter, listing detail, post/edit/mark-
    rented/delete my listings with up to 10 photos, favorites (server-synced),
    chat (polling every few seconds while a chat is open; no websockets yet),
    landlord verification (private upload + admin review), report listing/user,
    block user, profile (view/edit), privacy policy + terms screens, account
    deletion, Android app. DEFERRED (document in docs/decisions.md, tell users
    in release notes): interactive map, push notifications, checkout notices,
    listing-by-code, iOS, web client, ratings.
D2  Conversations model: two participants stored directly on `conversations`
    (participant_a, participant_b). Drop `conversation_participants`.
D3  Admin model: only `users.is_admin`. Delete `admin_roles` and the
    ADMIN_EMAILS authorisation path. First admin is created by a CLI
    subcommand: `unadomot-api admin grant <email>`.
D4  Access token lifetime 15 minutes; refresh token 30 days, rotating, with
    reuse detection (replay revokes the whole token family).
D5  Listing statuses: available | rented | removed_by_admin. Owners may only
    toggle available<->rented. Only admins may set/clear removed_by_admin.
D6  Email delivery: implement an `EmailSender` trait with an SMTP implementation
    (lettre) configured by env, plus a `LogEmailSender` for dev/tests. Do not
    hard-code a vendor.
D7  Google sign-in: client obtains a Google ID token; backend verifies
    signature (Google JWKS, cached), `aud` = configured client id, `iss`,
    `exp`, and `email_verified = true`; then upserts/links by verified email.
D8  ID documents: uploaded to a PRIVATE Cloudinary asset (type=authenticated)
    via a server-signed upload; stored as public_id only (never a public URL);
    admins view through short-lived signed URLs generated by the API.
D9  Config: one typed `Config` loaded and validated once at startup;
    APP_ENV = development | staging | production. In production every required
    value must be present or the process exits non-zero with a clear message.
D10 Search: add pg_trgm + a `search` query parameter over title/address/lga;
    state/lga/property_type/furnishing matched case-insensitively. Keep offset
    pagination for browse but ALSO add keyset (cursor) pagination and use it in
    the app.
D11 Money: price remains NUMERIC(14,2) / Decimal, transported as a string.
    Display currency NGN with "per year" copy only where the listing says so
    (add `rent_period` enum: year|month, default year).
